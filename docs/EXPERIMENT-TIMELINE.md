# Experiment Timeline

The repository preserves the complete 0001–0020 experiment record. This timeline makes the development path visible without relying on an unreconstructed historical commit sequence.

## 0001–0008: Establishing the executable learning loop

- **0001–0002:** verified skills and bounded symbolic search established the first reliable acquisition baselines.
- **0003–0004:** multi-family routing and content discrimination exposed the limits of prose-only compression.
- **0005–0007:** typed executable representations, composition, and bounded missing-skill handling improved reliability.
- **0008:** a bounded Python/API capability was acquired by the artifact path while the model-only condition failed.

## 0009–0012: Testing the frozen generic learner

- **0009:** generic acquisition remained weak under a frozen learner, with no wrong activation.
- **0010:** documentation-driven acquisition worked for several bounded API families but was not uniformly reliable.
- **0011:** retrieval plus executable artifacts reduced reuse cost and enabled model-free reuse.
- **0012:** storage and indexing scaled, while generic acquisition degraded as the state and document workload grew.

## 0013–0017: Locating the model-side boundary

- **0013:** faceted retrieval and scoped composition controlled large metadata collections.
- **0014:** context reduction was strong, but decomposition and new activation remained weak.
- **0015:** structured synthesis and repair improved retrieval diagnostics without producing successful new activations.
- **0016:** contract induction was isolated as a central bottleneck.
- **0017:** a model-free oracle compiler succeeded where direct model-generated semantic IR failed.

## 0018–0020: Verified external procedural memory

- **0018:** bounded search generated the correct candidate set; model ranking helped but was not sufficient by itself.
- **0019:** behavioral canonicalization removed duplicate behavior reliably, while documentation-based ranking remained limited.
- **0020:** verified procedures accumulated, persisted across cold restart, transferred to held-out tasks, and composed without incremental model calls.

## Final interpretation

The sequence supports a precise conclusion: the project produced a reliable bounded external procedural-memory system around a frozen small language model, but it did not demonstrate general continual semantic learning in the base model.
