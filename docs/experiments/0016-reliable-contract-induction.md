# Experiment 0016 — Reliable Contract Induction from Novel Documentation

Under the frozen Experiment 0015 conditions, retrieval was 5/5 but contract extraction was 0/5 in all three acquisition arms. Experiment 0016 is therefore not an end-to-end planning or skill-composition experiment; it isolates contract induction as a prerequisite for a later end-to-end study.

## Gate and frozen conditions

The Experiment 0015 gate did not pass: ACTIVE novel skills: 0; hidden/edge transition: 0; held-out reuse: none; structured-synthesis advantage: none; diagnostic repair success: none. The largest failure bucket was `contract_extraction_failure`. Experiment 0016 therefore measures contract reliability without adding planning or orchestration code.

The runtime was unchanged:

- `ggml-org/SmolLM3-3B-GGUF:Q4_K_M`, llama.cpp, CPU, context 4096;
- model weights and model selection frozen;
- the Experiment 0013 canonical learned state, facet/fingerprint retrieval, deduplication, scoped composition, sandbox, verifier, and Experiment 0015 synthesis boundaries frozen;
- eight opaque families (five from seed 1201 and three from independent seed 1202), three of which were absent from Experiment 0015;
- no family-specific prompt; SHA-256 values for all new prompts recorded before the first real model call;
- a timeout is a result; no silent retries. Runtime JSON is excluded from Git.

## Four measurement arms

| Arm | Protocol |
|---|---|
| A — `free_form` | The previous Experiment 0015 contract prompt; the model extracts both structural and semantic contract fields. |
| B — `structured_one_shot` | The system deterministically supplies the module, callable, signature, types, and allowlist; the model extracts seven semantic fields in one call. |
| C — `field_by_field` | Each semantic field is extracted in a separate call. |
| D — `evidence_grounded` | The same field separation as C; each claim is linked to a selected document ID and a quote/span from the document. |

The canonical `air-contract-v1` schema contains these semantic fields:
`operation_summary`, `preconditions`, `postconditions`,
`semantic_invariants`, `ordering_constraints`, `special_cases`, and
`failure_behavior`. Structural metadata is generated by the system; undocumented callables or imports invented by the model are not accepted.

An oracle downstream probe also ran for every arm. The oracle measures the same single downstream semantic-body call using the true semantic ground truth; it is an upper-bound control independent of contract extraction. The extracted probe runs only for a `COMPLETE` contract and performs no repair.

Because structural fields are deterministic in Arms B, C, and D, the accuracy of `module`, `callable`, `signature`, `input_type`, `output_type`, `allowed_imports`, and `allowed_calls` was 100%. This confirms that the structural-extraction error from Experiment 0015 was removed; however, the activation gate remained closed because the semantic contract was incomplete.

The main remaining error was that the model frequently returned `unknown` for `postconditions`, `semantic_invariants`, `special_cases`, and `failure_behavior`. Field-by-field extraction improved `operation_summary`, but it did not complete all critical fields together. In the evidence-grounded arm, approximately half of the claims were linked to a real document span; adding evidence alone did not bring semantic accuracy to the complete-contract level.

There were eight physical oracle downstream probes; the same oracle result is shown in each arm’s view. Even when given the correct contract, the model often mixed the semantic body with wrapper/import code or failed the public probe. Experiment 0016 therefore did not demonstrate the acquisition engine’s downstream upper bound.

## Failure taxonomy and decision

Runtime counts:

```text
semantic_extraction_failure  182 field errors
incomplete_contract            24 arm-family outcomes
evidence_failure               29 evidence errors
oracle_downstream_failure      32 arm views / 8 physical oracle calls
structural_metadata_failure     8 (Arm A)
schema_failure                  0
retrieval_failure               0
timeout                         0
wrong_activation                0
```

The largest bucket was **semantic extraction failure**. Relative to Experiment 0015, structural metadata was no longer required from the model and structural accuracy was 100% in Arms B/C/D. The decision nevertheless remains:

- complete valid contracts: **0/8**;
- ACTIVE skills, hidden/edge validation, and held-out reuse: **0**;
- wrong activation and regression of the existing library: **0 / none**;
- Experiment 0016 is not a sufficient gate for end-to-end capability accumulation;
- Experiment 0017 or a planning/composition layer should not be selected before this gate is resolved.

A subsequent study would need to target this failure bucket directly, using the same frozen prompt and model to measure reliable completion of semantic fields, repair, and abstention. This report makes no claim of general programming, continual learning, or AGI.
